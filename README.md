# Bo Pan's Academic Homepage

Personal academic website: [pb0316.github.io](https://pb0316.github.io/).

## Content

- `_data/profile.yml`: biography, contact details, education, and industry experience.
- `_publications/all/`: publication metadata and links.
- `_news/`: dated news items.
- `_data/display.yml`: homepage section settings.

## Local preview

```sh
bundle install
bundle exec jekyll serve
```

Open the local URL printed by Jekyll. To check a production build, run `bundle exec jekyll build`.
